Savuor v1.0.0
=============

Install SavuorSetup.exe, then launch Savuor from the Start Menu or desktop shortcut.

First launch
------------
Enter your personal Groq API key, then choose Save & Continue.
The key is stored with Windows encryption for this user only.

Windows permissions
-------------------
Microphone: Settings > Privacy & security > Microphone > allow Savuor.
System audio: allow screen/audio capture when Windows asks.
Network: required for Groq AI answers.

Uninstall
---------
Use Windows Apps & features. You can keep or remove saved settings and API credentials.

Logs
----
%APPDATA%\Savuor\logs
Open from Savuor Settings > Open logs.
